# Plot

A personal project planner. Each project is a 2D desk: markdown notes sit beside Excalidraw drawings, and you can draw links between them.

Stack: **Bun + Hono** API, **Vite + React** UI, Tailwind CSS v4 + shadcn/ui.

## Features

- Username + password accounts, profile, avatar
- First account is admin: `/admin` to list, create, reset, or delete users
- Dashboard of boards, personal folders, All / Mine
- Pan/zoom canvas with markdown, Excalidraw, image, and file spaces
- Share by username (view / edit) and public `/s/:slug` links
- Trash, restore, and permanent delete for boards and spaces
- Global search and in-canvas search
- Autosave through the API

## Install

You need [Bun](https://bun.sh).

```bash
bun install
```

SQLite, PostgreSQL, MySQL, password hashing, S3, and the HTTP server come from Bun itself. No extra database or AWS SDK packages.

## Run locally

```bash
cp .env.example .env
bun run dev
```

- App: [http://127.0.0.1:5173](http://127.0.0.1:5173)
- API: [http://127.0.0.1:3001](http://127.0.0.1:3001) (`/api` is proxied from Vite)

Create an account. A starter board is created for you.

Defaults (no extra setup):

| Variable | Default |
| --- | --- |
| `DB_BACKEND` | `sqlite` → `data/planner.db` |
| `STORAGE_BACKEND` | `local` → `data/uploads` |

## Deploy

```bash
cp .env.production.example .env
# fill in APP_URL, DATABASE_URL, S3_*  (or keep sqlite + local disk)
bun run build
bun run start
```

That serves the built UI and the API together on `PORT` (default `3001`).

Put HTTPS in front (Caddy, nginx, Traefik) and set:

```env
NODE_ENV=production
APP_URL=https://your.domain
COOKIE_SECURE=true
REGISTRATION_ENABLED=true
```

`COOKIE_SECURE` defaults to `true` when `NODE_ENV=production`. Set it `false` only if you are serving plain HTTP.

Set `REGISTRATION_ENABLED=false` to block new signups. Existing accounts can still sign in. `/api/health` reports the flag. The first account in the database can still create users at `/admin`.

Health check:

```bash
curl -s http://127.0.0.1:3001/api/health
# { "ok": true, "db": "postgres", "storage": "s3", "registrationEnabled": true }
```

Env templates:

- [`.env.example`](.env.example) — local
- [`.env.production.example`](.env.production.example) — production

### Database (`DB_BACKEND`)

| Value | Connection |
| --- | --- |
| `sqlite` (default) | `SQLITE_PATH` (default `data/planner.db`) |
| `postgres` | `DATABASE_URL=postgres://user:pass@host:5432/plot` |
| `mysql` | `DATABASE_URL=mysql://user:pass@host:3306/plot` |

`msql` is accepted as an alias for `mysql`.

Create the Postgres/MySQL database first. Plot creates tables on boot. Existing SQLite files keep working.

### File storage (`STORAGE_BACKEND`)

| Value | Where files go |
| --- | --- |
| `local` (default) | `UPLOAD_DIR` (default `data/uploads`) |
| `s3` | S3-compatible bucket (AWS, MinIO, R2, Spaces, B2, …) |

Uploads stay at `/api/files/:id`. With `s3`, Plot writes the object and streams it back unless `S3_PUBLIC_URL` is set, in which case that route 302s to the public/CDN URL.

| Variable | Notes |
| --- | --- |
| `S3_ENDPOINT` | Required for MinIO / R2 / Spaces. Optional for AWS. |
| `S3_REGION` | Default `us-east-1` |
| `S3_BUCKET` | Required |
| `S3_ACCESS_KEY` / `S3_SECRET_KEY` | Also accepts `S3_ACCESS_KEY_ID` and `AWS_*` |
| `S3_FORCE_PATH_STYLE` | Default `true` when `S3_ENDPOINT` is set (MinIO) |
| `S3_PREFIX` | Object prefix, default `uploads` |
| `S3_PUBLIC_URL` | Optional public / CDN base |

### Docker

```bash
cp .env.production.example .env
cp docker-compose.example.yml docker-compose.yml
# edit credentials
docker compose up --build
```

[`docker-compose.example.yml`](docker-compose.example.yml) runs Plot + Postgres + MinIO.

Single container with sqlite and local disk:

```bash
docker build -t plot .
docker run --rm -p 3001:3001 \
  -e NODE_ENV=production \
  -e DB_BACKEND=sqlite \
  -e STORAGE_BACKEND=local \
  -v plot-data:/app/data \
  plot
```

Mount `/app/data` so the database and uploads survive restarts.

## Using a board

- **+ Note** or `N` — markdown space
- **+ Drawing** or `D` — Excalidraw space
- Double-click a card to open it
- Drag the handles to link two spaces
- Double-click a link to label it
- Delete / Backspace removes the selected card or link
- Positions, sizes, writing, drawings, and the camera are saved automatically
